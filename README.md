# BBS Exam Mission Planner

A mobile-responsive study planner and to-do app designed to track BBS exam preparation, daily routines, programming practice, client hunting, English speaking, and exam progress.

## How to Use

1. Go to the link: https://exam-plannar.vercel.app/
2. Open in any modern web browser.
3. Select a date from the calendar to view daily tasks.
4. Tick the checkbox when a task is completed.
5. Use **Add Task** to create custom tasks.
6. Your progress is automatically saved in the browser using `localStorage`.

### Features
- Full Calendar
- Daily Time-based Tasks
- Exam Schedule
- Progress Tracking
- Custom Tasks
- Mobile Responsive
- LocalStorage Data Saving

No backend or installation is required.
